# 🌸 Bloom

Bloom é um aplicativo desenvolvido em Python utilizando Streamlit para acompanhar hábitos diários.

## Objetivos

- Criar hábitos personalizados
- Definir metas semanais
- Acompanhar evolução
- Visualizar estatísticas
- Aprender Python durante o desenvolvimento

## Tecnologias

- Python
- Streamlit
